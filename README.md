# Day 15 - Product Count Analysis

## Objective
To count products by category and identify the category with the highest product count.

## Tool Used
- Microsoft Excel

## Dataset
- Sample Superstore Dataset

## Work Done
- Counted products in each category using COUNTIF.
- Created a product count table.
- Identified the largest category.
- Created a column chart to compare product counts.

## Results

| Category | Product Count |
|---|---:|
| Furniture | 957 |
| Office Supplies | 2772 |
| Technology | 847 |

### Largest Category
**Office Supplies - 2772 products**
